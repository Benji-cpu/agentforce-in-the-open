**Customer:** Can I return some beakers I ordered three weeks ago? They're still in the box, unopened.

**Agent (8.3s):** Yes, you can return the beakers if they are unused and still in their unopened original packaging. Returns are accepted within 30 days of delivery for a full refund of the goods, but you would need to pay the return postage unless the items were faulty or sent in error.

To start a return, please email returns@northaven-instruments.example with your order reference and the reason. You will receive a returns number and label within one working day.
