# Northaven Instruments — synthetic dataset

**None of this is real.** Northaven Instruments does not exist; nor do the schools, labs,
people, emails or orders below. It exists so the agent has something to look up. Every name
was invented for this repo and any resemblance to a real organisation is accidental.

Load it with:

```bash
./sf data import tree --plan data/northaven/plan.json --target-org agentforce-de
```

Eight customers, ten contacts, twelve orders spread across every fulfilment status, with
two orders carrying calibrated instruments so the certificate question has something to
answer. The order references (`NI-2041` …) are what a customer would quote; the email on
the bill-to contact is what the lookup verifies against.
